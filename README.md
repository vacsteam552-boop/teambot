# Sailent TEAM — Telegram Application Bot

Два Telegram-бота для приёма заявок и админ-панели.

| Бот | Назначение |
|-----|------------|
| **Основной** | Пошаговая форма заявки для пользователей |
| **Админ** | Просмотр, одобрение/отклонение заявок, переписка с кандидатами |

## Возможности

**Основной бот**
- Пошаговая анкета: правила → ГЕО / без опыта → опыт → мануал → вопросы
- Для новичков: успокаивающее сообщение об обучении с нуля и поддержке 24/7
- Обязательное ознакомление с мануалом перед продолжением
- Уведомление об отправке заявки

**Админ-бот**
- Доступ только для указанного `@username`
- Список заявок (новые / одобренные / отклонённые)
- Одобрение с отправкой ссылки на Discord
- Отклонение с уведомлением
- Отправка сообщений пользователю от лица основного бота

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone <url>
cd telegram-application-bot
```

### 2. Настроить окружение

```bash
copy .env.example .env   # Windows
# cp .env.example .env   # Linux / macOS
```

Заполните `.env`:

```env
MAIN_BOT_TOKEN=...
ADMIN_BOT_TOKEN=...
ADMIN_USERNAME=s4toshi11
DISCORD_INVITE=https://discord.gg/EkAZWtz3wr
MANUAL_URL=https://teletype.in/@krutoyparen/13kAtDSwiE6
```

### 3. Установить зависимости и запустить

**Windows:**
```bat
run.bat
```

**Вручную:**
```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate # Linux / macOS
pip install -r requirements.txt
python run.py
```

### 4. Активировать админ-бот

После первого запуска отправьте `/start` в **админ-боте** с аккаунта `@ADMIN_USERNAME`.

## Сценарии заявки

### С опытом
1. `/start` → правила → «Далее»
2. Выбор ГЕО (Китай / Европа / Америка / Другое)
3. Ответы об опыте одним сообщением
4. Мануал → «✅ Я все понял»
5. Сколько времени готов уделять ворку
6. Заявка отправлена

### Без опыта
1. `/start` → правила → «Далее»
2. «🚫 Без опыта»
3. Сообщение об обучении с нуля и поддержке 24/7 → «Далее»
4. Мануал → «✅ Я все понял»
5. Время на ворк → Prime в CS2
6. Заявка отправлена

## Деплой на сервер

Для постоянной работы используйте systemd, pm2 или screen/tmux:

```bash
nohup python run.py > bot.log 2>&1 &
```

На Windows — Task Scheduler или запуск `run.bat` при старте системы.
